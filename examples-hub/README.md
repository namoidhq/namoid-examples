# NamoID examples hub

Public directory for hosted NamoID demos. Deploy it as a Vercel project with
`examples-hub` selected as the Root Directory.

## Local development

```bash
pnpm install
pnpm dev
```

## Vercel

- Framework preset: Vite
- Root Directory: `examples-hub`
- Build command: `pnpm build`
- Output directory: `dist`
- Custom domain: `examples.namoid.in`

No NamoID credentials are required by the hub itself.
