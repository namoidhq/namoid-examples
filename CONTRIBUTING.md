# Contributing to NamoID

Thanks for your interest in improving NamoID! This repo is one of several
open-source projects under the [`namoidhq`](https://github.com/namoidhq) org.

## Filing issues

Found a bug or have a feature request? Open an issue in this repo's
[Issues](../../issues) tab. Please search existing issues first, and include
enough detail for us to reproduce (which example, your environment, steps).
Security issues should **not** be filed publicly — see
[SECURITY.md](./SECURITY.md).

## Submitting a pull request

1. Fork and create a branch from `main`.
2. Make your change. Keep it focused — one logical change per PR.
3. Make sure examples still run and any tests pass (see below).
4. Open the PR and link the related issue (e.g. `#123`).

We aim to review PRs promptly. Be patient and kind — this is maintained by a
small team.

## Local development

Each example is self-contained. Pick a stack directory (e.g. `node-express/`,
`python-fastapi/`), copy its `.env.example`, and follow that example's own
`README.md` to run it. There's no monorepo build step at the root.
